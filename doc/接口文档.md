## 1. 获取文件列表

```
GET /api/files?path=<relativePath>
```

获取指定目录下的文件和文件夹列表，文件夹排在前面，按名称字母排序，隐藏文件（以 `.` 开头）不显示。

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| `path` | query | string | 否 | 相对根目录的路径，空字符串或不传表示根目录 |

### 响应 200

```json
{
  "path": "",
  "files": [
    { "name": "documents", "type": "dir",  "size": 0,   "mtime": "2026-04-30T02:20:54.814Z" },
    { "name": "images",    "type": "dir",  "size": 0,   "mtime": "2026-04-30T02:20:55.068Z" },
    { "name": "readme.txt","type": "file", "size": 10,  "mtime": "2026-04-30T02:20:55.260Z" }
  ]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 文件/文件夹名称 |
| `type` | string | `"dir"` 表示文件夹，`"file"` 表示文件 |
| `size` | number | 文件大小（字节），文件夹为 0 |
| `mtime` | string | ISO 8601 格式的最后修改时间 |

### 错误码

- `400 PATH_TRAVERSAL` — 路径越权访问被拒绝
- `404 DIR_NOT_FOUND` — 目录不存在

### 移动端调用示例

```javascript
// 获取根目录文件列表
const res = await fetch('http://192.168.1.100:3000/api/files?path=');
const data = await res.json();
data.files.forEach(f => console.log(f.name, f.type));

// 进入子目录
const res2 = await fetch(`http://192.168.1.100:3000/api/files?path=documents`);
const subData = await res2.json();
```

## 3. 上传文件

```
POST /api/upload
Content-Type: multipart/form-data
```

上传文件到指定目录，支持多文件上传。

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `path` | string | 是 | 目标目录的相对路径 |
| `files` | file[] | 是 | 文件数组，字段名固定为 `files` |
| `strategy` | string | 否 | 重名处理策略，`"overwrite"`（覆盖，默认） |

### 响应 200

```json
{
  "message": "上传成功",
  "files": [
    { "name": "readme.txt", "size": 10 }
  ]
}
```

### 错误码

- `413 FILE_TOO_LARGE` — 文件超过大小限制（默认 2GB）

### 移动端调用示例

```javascript
// 从移动端相册选择文件上传
const form = new FormData();
form.append('path', 'documents');
form.append('files', selectedFile);   // File 对象
form.append('strategy', 'overwrite');

const res = await fetch('http://192.168.1.100:3000/api/upload', {
  method: 'POST',
  body: form,
});
const result = await res.json();
```

## 4. 删除文件/文件夹

```
DELETE /api/files
Content-Type: application/json
```

将文件或文件夹移动到回收站。删除非空文件夹时会递归删除内部所有文件后移入回收站。

### 请求 Body

```json
{
  "path": "documents/old-report.pdf"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `path` | string | 是 | 要删除的文件或文件夹的相对路径 |

### 响应 200

```json
{
  "message": "删除成功"
}
```

### 错误码

- `400 PATH_TRAVERSAL` — 路径越权访问被拒绝
- `404 DIR_NOT_FOUND` — 文件或目录不存在
- `409 FILE_IN_USE` — 文件正在被其他程序使用，无法删除


## 7. 单文件下载

```
POST /api/download
Content-Type: application/json
```

将文件复制到指定的本地路径。响应为流式 Newline-Delimited JSON，实时返回复制进度。

### 请求 Body

```json
{
  "path": "documents/report.pdf",
  "destination": "D:\\Backup\\report.pdf"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `path` | string | 是 | 源文件的相对路径 |
| `destination` | string | 是 | 目标完整路径（包含文件名） |

### 响应格式

`Content-Type: application/x-ndjson`

逐行输出 JSON：

```
{"progress":30}
{"progress":65}
{"progress":100,"done":true}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `progress` | number | 复制进度百分比（0-100） |
| `done` | boolean | 仅在最后一行出现，标记完成 |

### 错误行

```
{"error":"磁盘空间不足"}
```

### 错误码

- `400 INVALID_DEST` — 目标路径不能为空
- `400 NOT_A_FILE` — 只能下载文件
- `404 FILE_NOT_FOUND` — 源文件不存在
- `507 ENOSPC` — 磁盘空间不足

### 移动端调用示例

```javascript
// 下载文件并显示进度
const resp = await fetch('http://192.168.1.100:3000/api/download', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    path: 'documents/report.pdf',
    destination: '/storage/emulated/0/Download/report.pdf',
  }),
});

const reader = resp.body.getReader();
const decoder = new TextDecoder();
let buffer = '';

while (true) {
  const { done, value } = await reader.read();
  buffer += decoder.decode(value, { stream: !done });
  const lines = buffer.split('\n');
  buffer = lines.pop() || '';
  for (const line of lines) {
    if (!line.trim()) continue;
    const data = JSON.parse(line);
    if (data.error) throw new Error(data.error);
    if (data.progress != null) console.log('进度:', data.progress + '%');
  }
  if (done) break;
}
console.log('下载完成');
```

## 8. 批量下载

```
POST /api/download/batch
Content-Type: application/json
```

批量下载多个文件/文件夹到目标目录。支持文件和文件夹混合选择，文件夹内部递归复制所有文件。响应为流式 Newline-Delimited JSON。

### 请求 Body

```json
{
  "paths": ["documents/report.pdf", "images/", "readme.txt"],
  "destination": "D:\\Backup"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `paths` | string[] | 是 | 相对路径数组，可混合文件/文件夹 |
| `destination` | string | 是 | 目标目录路径 |

### 响应格式

```
{"progress":20,"currentFile":"documents/report.pdf"}
{"progress":40,"currentFile":"images/photo.jpg"}
{"progress":60,"currentFile":"images/logo.png"}
{"progress":100,"done":true}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `progress` | number | 整体进度百分比（0-100） |
| `currentFile` | string | 当前正在复制的文件相对路径 |
| `done` | boolean | 仅在最后一行出现，标记完成 |

### 错误行

```
{"error":"磁盘空间不足"}
```

### 错误码

- `400 INVALID_PATHS` — 请选择至少一个文件或文件夹
- `400 INVALID_DEST` — 目标路径不能为空
- `400 NO_FILES` — 所选项目中无文件可复制
- `400 PATH_TRAVERSAL` — 路径越权访问被拒绝
- `507 ENOSPC` — 磁盘空间不足

## 统一错误格式

所有接口在出错时返回统一的 JSON 结构：

```json
{
  "code": "ERROR_CODE",
  "message": "人类可读的错误描述"
}
```

## 附录：状态码说明

| HTTP 状态码 | `code` | 说明 |
|------------|--------|------|
| 400 | `PATH_TRAVERSAL` | 路径越权访问被拒绝（检测到 `../` 等越级路径） |
| 400 | `INVALID_NAME` | 文件/文件夹名称不能为空 |
| 400 | `INVALID_DEST` | 目标路径不能为空 |
| 400 | `INVALID_PATHS` | 未选择任何项目 |
| 400 | `NOT_A_FILE` | 应传入文件路径但传了文件夹路径 |
| 400 | `NO_FILES` | 所选项目中无文件可复制 |
| 404 | `DIR_NOT_FOUND` | 目录或文件不存在 |
| 404 | `FILE_NOT_FOUND` | 源文件不存在 |
| 409 | `FILE_IN_USE` | 文件正在被其他程序使用，无法操作 |
| 413 | `FILE_TOO_LARGE` | 上传文件超过大小限制 |
| 507 | `DISK_FULL` | 磁盘空间不足 |
| 500 | `INTERNAL_ERROR` | 服务器内部错误 |
